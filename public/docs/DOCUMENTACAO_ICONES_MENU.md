# Documentação e Refinamento Semântico dos Ícones do Menu Lateral
## Centro de Treinamento e Desenvolvimento Doutrinário do Corpo de Fuzileiros Navais (CTDDCFN)
### Tema Institucional Drupal 10+ / Design System Stitch (Material Symbols Outlined v2.0)

---

## 1. Visão Geral e Princípios de Design
Esta documentação estabelece o padrão formal de correspondência semântica entre os títulos, conteúdos e os glifos vetoriais utilizados no menu lateral esquerdo do Portal CTDDCFN.

### Diretrizes de Homologação:
1. **Fonte Única Homologada**: Google Material Symbols Outlined (ligaduras oficiais).
2. **Eliminação de Ambiguidade**: Nenhum ícone puramente decorativo ou abstrato. Cada glifo reflete a natureza administrativa, operacional, acadêmica ou tática da página associada.
3. **Resolução de Inconsistências Anteriores**:
   - Correção do termo inválido `globe` (não existente no Google Material Symbols) para `public`.
   - Substituição de caixas genéricas (`inventory_2`) por coletâneas de publicações (`collections_bookmark`).
   - Substituição de estrelas genéricas (`star`) por insígnias de comando militar (`military_tech`).
   - Substituição de ícones industriais fabris (`precision_manufacturing`) por alta tecnologia e cibernética (`memory`).
   - Substituição de formulários genéricos de planilhas (`table_view`) por credenciamento formal de vagas (`how_to_reg`).
   - Substituição de cadernos (`menu_book`) em autenticação Zimbra por segurança criptográfica de e-mail (`mail_lock`).

## 3. Implementação no Tema Drupal 10 (Twig Template)

Para renderizar estes ícones no tema oficial Drupal 10 (`ctddcfn_theme`), utilize o template `menu--sidebar.html.twig`:

```twig
{# templates/navigation/menu--sidebar.html.twig #}
{% import _self as menus %}

<nav class="sidebar-menu" aria-label="Menu Institucional">
  {% for category, items in menu_categories %}
    <div class="menu-category py-4">
      <h3 class="category-title font-bold text-xs uppercase text-[#002E32] mb-2 px-3">
        {{ category }}
      </h3>
      <ul class="space-y-0.5">
        {% for item in items %}
          <li>
            <a 
              href="{{ item.url }}" 
              class="flex items-center justify-between px-3 py-1.5 rounded transition text-xs {% if item.in_active_trail %}bg-[#002E32] text-white font-bold{% else %}text-[#404848] hover:bg-[#eef2f1]{% endif %}"
              title="{{ item.title }} — {{ item.icon_rationale }}"
            >
              <span class="flex items-center gap-2 truncate">
                <span class="material-symbols-outlined text-sm shrink-0 {% if item.in_active_trail %}text-[#BAD435]{% else %}text-[#707979]{% endif %}">
                  {{ item.icon }}
                </span>
                <span class="truncate">{{ item.title }}</span>
              </span>
            </a>
          </li>
        {% endfor %}
      </ul>
    </div>
  {% endfor %}
</nav>
```

## 4. Tokens de Estilo Aplicados (Material Design 3 & Stitch)

- **Cor Primária**: `#002E32` (`--color-graphite-teal-deep`)
- **Cor de Acento / Ativação**: `#BAD435` (`--color-renewal-green`)
- **Superfície dos Cards**: `#F7FAF9` (`--color-surface`)
- **Bordas & Delimitadores**: `#C0C8C9` (`--color-outline-variant`)
- **Ícones em Estado Inativo**: `#707979` (`--color-outline`)
- **Ícones em Estado Ativo**: `#BAD435` com escala `scale-110` e fundo `#002E32`
